# Junie guidelines

All assistant guidance lives in `AGENTS.md` files. Before any task:

1. Read the root `AGENTS.md` (repo map, commands, healthcare data rules).
2. Read the `AGENTS.md` of the area you are working in:
   - `packages/healthcare-ai-core/AGENTS.md`
   - `services/AGENTS.md` (and `services/<name>/AGENTS.md` once a service exists)
